
# FastIndex

FastIndex is a cross-platform desktop application for
fast indexing and full-text searching of local files.

## Tech Stack

- C++20
- Qt 6 / QML
- SQLite FTS5
- CMake / Ninja
- GoogleTest
- Google Benchmark

## Project Status

Early development.

Current functionality:
- Qt Quick desktop application
- CMake build with C++20

## Goals

- Recursive file scanning
- Concurrent file processing
- SQLite full-text search
- Responsive desktop UI
- Automated testing and benchmarking
